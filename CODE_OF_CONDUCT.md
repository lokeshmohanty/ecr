# Code of conduct

## The short version

Be decent. Assume the other person is acting in good faith, argue about the code
rather than the person writing it, and accept that a maintainer's "no" is an
answer rather than an opening position.

## The longer version

This project adopts the [Contributor Covenant v2.1][cc]. The full text is worth
reading, but what it comes down to in a project this size:

**Expected:** technical disagreement, direct feedback, saying "I don't
understand this" without embarrassment, and changing your mind in public.

**Not expected:** harassment of any kind, sexualised language or imagery,
personal or political attacks, publishing someone's private information, or
persistently reopening a settled decision.

## Scope

This applies in the issue tracker, in pull requests, in commit messages and
anywhere someone is representing the project.

## Enforcement

Report a problem through
[GitHub's private reporting](https://github.com/lokeshmohanty/ecr/security/advisories/new)
or by contacting the maintainer directly. Reports are handled privately.

The maintainer will do one of: nothing, a private word, editing or removing the
contribution, or a ban. There is no appeals process and no committee — this is a
one-person project, and pretending otherwise would be theatre.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
